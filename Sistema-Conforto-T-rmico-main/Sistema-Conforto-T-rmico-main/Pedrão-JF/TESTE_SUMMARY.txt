🛠️  COMO EXECUTAR OS TESTES
═══════════════════════════════════════════════════════════════════════════

1. Instalar dependências:
   pip install -r requirements.txt pytest

2. Executar todos os testes:
   python run_tests.py all
   
   OU
   
   python -m pytest tests/test_rules.py -v

3. Executar teste específico:
   python run_tests.py rules         # Apenas regras
   python run_tests.py classifier    # Apenas classifier
   python run_tests.py tree          # Apenas Decision Tree
   python run_tests.py integration   # Apenas integração

4. Ver cobertura de código:
   pip install pytest-cov
   pytest tests/test_rules.py --cov=src --cov-report=html
